<summary><b>🧠 &nbsp;Peek inside ColdMailAI — how the LLM pipeline is wired</b></summary>
<br/>

```mermaid
flowchart LR
    U([👤 Client]) -->|JWT| G[🛡️ API Gateway<br/>auth · rate limit]
    G --> P[🧩 Prompt Pipeline<br/>templating · context]
    P --> R{⚖️ Model Router}
    R -->|low latency| Q[⚡ Groq]
    R -->|heavy lift| N[🟩 NVIDIA NIM]
    Q --> V[✅ Policy Validator<br/>schema · filters]
    N --> V
    V -->|valid| O([📨 Structured Output])
    V -.->|reject / retry| P

    classDef core fill:#0f172a,stroke:#38bdf8,color:#e0f2fe;
    classDef llm fill:#1e1b4b,stroke:#a78bfa,color:#ede9fe;
    class G,P,R,V core;
    class Q,N llm;
```

<sub>Non-deterministic model in → deterministic contract out.</sub>
