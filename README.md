## About

I'm **Shaan** — a full stack engineer who designs, builds and writes. I study Computer Science at **IIIT Bhubaneswar** and spend most of my time shipping production software alongside it.

Right now I'm building **[Acadex](https://acadex.ereefian.com)** at **Ereefian** — an academic platform that runs students, teachers and admins from a single MERN codebase. I led user research with **500+ students and 30+ professors**, designed the UI from the ground up, and owned the system design for RBAC, events and notifications. That modular architecture cut feature release cycles by **40%**, and query + schema work brought average API response time down **35%**.

Outside of product work I build things that feel alive — a real-time voice agent that answers in **under 400ms**, and a WebGL Manhattan rebuilt from NYC Open Data. I also write: screenplays and short stories under the pen name **Moryasshan**, and essays on AI agents and agentic commerce.
